A wallet and simple swap on Robinhood Chain

Authorize every detail of every swap.

QEVRA is a wallet and a simple swap for Robinhood Chain. It is designed to lock every swap detail you reviewed, and it explores post-quantum authorization in the open.

Explore Security

    The Security Swarm researches, tests, and reports. It does not control your wallet.

    What the Swarm can and cannot do

    QEVRA’s agents do not access your private keys, sign transactions on your behalf, or move your funds. They work with public security information and isolated test environments.

    Proposed security changes must pass deterministic tests, appropriate security review, and explicit human approval before deployment.

                The Aperture design system

                The approved direction as tokens, type, parts and the 3D object. The handoff document QEVRA_DESIGN_DIRECTION.md carries the full specification, and this page is its live reference.

                ColourTypeSpace, radius, motionPartsThe 3D object

                Colour

                Graphite, warm silver, one warm light. The beam is tungsten, never green: lime is kept for a test that actually passed. Contrast is computed here with the WCAG 2 formula.

                Type

                Instrument Serif for display, Geist for the interface, Geist Mono for data. Sentence case throughout. No tracked capitals, no single emphasised word in a headline. Licences and loading are to be confirmed before production.
